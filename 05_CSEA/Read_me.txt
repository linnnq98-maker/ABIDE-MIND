# Cell Type-Specific Expression Analysis (CSEA)

Cell type-specific expression analysis was performed using the
Dougherty Lab CSEA web tool:

http://doughertytools.wustl.edu/CSEAtool.html

Reference:
Xu et al., Journal of Neuroscience, 2014.

Four gene sets were separately submitted:
1. ASD1 PLS1-positive genes
2. ASD1 PLS1-negative genes
3. ASD2 PLS1-positive genes
4. ASD2 PLS1-negative genes

CSEA was performed using a specificity index probability (pSI)
threshold of 0.05.

Multiple-comparison correction was performed using the
Benjamini–Hochberg false discovery rate (BH-FDR), with
FDR < 0.05 considered statistically significant.
