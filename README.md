# ABIDE-MIND
# Code and Derived Data for MIND-Based ASD Subtyping Analyses

This repository contains the analysis code, key input files, and derived
data used for the MIND-based autism spectrum disorder (ASD) subtyping
analyses described in the manuscript.

The repository is organized into five main analysis components:

1. MIND network construction and subtype-versus-control t-maps
2. HYDRA subtyping
3. Partial least squares (PLS) and spatial permutation analyses
4. fgsea-based gene set enrichment analysis
5. Cell type-specific expression analysis (CSEA)

The purpose of this repository is to provide the key materials required to
reproduce the principal computational analyses and molecular association
analyses reported in the study.
